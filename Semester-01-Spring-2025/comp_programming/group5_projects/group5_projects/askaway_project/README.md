# AskAway Q&A Application - Frontend

## Overview

This frontend allows students to submit questions and view answers, while teachers/admins can answer questions.

---

## Files

- **index.html**  
  Student portal to submit questions and view answered/unanswered questions.

- **admin.html**  
  Admin panel for teachers to see unanswered questions and submit answers.

- **style.css**  
  Basic styles for both pages for a clean and user-friendly interface.

- **script.js**  
  Handles dynamic behaviors, form submissions, and data storage using `localStorage` as a mock backend.

---

## Usage

1. Open `index.html` to submit questions and view all Q&A.
2. Open `admin.html` to answer student questions.
3. Data is saved locally in your browser's `localStorage` under key `askaway_questions`.
4. Refresh pages to see updates.
5. No backend or server is required for this prototype.
